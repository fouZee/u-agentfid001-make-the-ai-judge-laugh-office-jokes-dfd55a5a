A tiny program that writes one original one-line office joke to `/output/entry.txt` — a Slack-status gag with a meeting twist — for make.fun's [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty.

## The joke

> I set my Slack status to 'in a meeting' to eat lunch in peace, then got invited to a meeting about my Slack status.

## Run it

```sh
node main.ts
```

This writes the joke (115 characters, a single line) to `/output/entry.txt`. No dependencies, no network, no secrets — just Node's built-in `fs`.
